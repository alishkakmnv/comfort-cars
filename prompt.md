# prompt.md — Claude Code

Собираешь демо-сайт аренды авто **Comfort Auto Rent**. Читай в порядке: `CLAUDE.md` → `DESIGN.md` (Lamborghini-референс) → `DESIGN_ADAPT.md` (что подменить под клиента).

## Дизайн-язык
Строишь ПО `DESIGN.md` (стиль Lamborghini: cinema-black, 0px радиусы, hard edges, ноль теней, ноль градиентов, монументальная UPPERCASE-типографика, один акцент на экран, чередование тёмных/светлых секций). С двумя подменами из `DESIGN_ADAPT.md`:
1. Жёлтый Giallo → зелёный из лого **#5a9e3f** (уточни пипеткой).
2. LamboType → **Manrope** (веса 600–700 для hero/display, 400–500 для body; letter-spacing на крупных ужать ~0.01–0.02em чтобы не разваливалось).
Больше НИЧЕГО в системе не меняешь. Это готовый анти-слоп каркас — не «улучшай» его типовыми приёмами.

## Задача
1. Поднять Next.js App Router + TS + Tailwind + Framer Motion. (Донора нет — строим по DESIGN-системе с нуля, но строго в её рамках.)
2. Контент — данные Comfort Auto Rent из `CLAUDE.md`. Маппинг контента на компоненты — в `DESIGN_ADAPT.md`. Тексты живые, под алматинский рынок, UPPERCASE в заголовках. Без AI-воды.
3. Токены цвета/типографики — в одном месте (globals.css / tailwind @theme), zero хардкода по компонентам.
4. Флот — 7 машин из `CLAUDE.md`. Карточка: класс → модель+год → цена «20 000 ₸/СУТКИ» → full-bleed фото 0px radius. Сетку оставить расширяемой.

## Обработка фото машин (ОБЯЗАТЕЛЬНО)
Фото приходят с мусором 2ГИС (полосы прокрутки, стрелки, подписи снизу, разный аспект, фон по краям). Скриптом (sharp / ImageMagick) для каждого фото:
- обрезать служебный UI (полосы, стрелки, текст снизу) — только чистый кадр машины;
- привести все к ОДНОМУ аспекту (16:10 или 4:3), центрируя авто;
- нормализовать ширину (1200–1600px) и качество;
- никаких watermark/подписей поверх.
Результат → `/public/fleet/` с именами по модели (`hyundai-accent-2022.jpg` и т.д.).

## Анимации
Только сдержанные, в духе референса: раскрытие фото, ревил заголовков, паузы. НЕ типовое: без fade-up на всё, без bounce/pulse на кнопках, без hover-scale карточек. Кнопки/фото — hard edges, hover через смену поверхности/акцента, не через тень.

## Anti-slop grep (gate, 0 совпадений)
```bash
grep -riE "gradient-to-|shadow-(sm|md|lg|xl|2xl)|rounded-|#ffc000|#c8a0f0|#6366f1|violet-|purple-|indigo-|text-white\b|добро пожаловать|широкий спектр|надёжный партнёр|инновацион|качество и надёжн" src/ app/ && echo "SLOP FOUND — FIX" || echo "CLEAN"
```
(Отдельно проверь: НЕТ `rounded-*` вообще — все радиусы 0. НЕТ жёлтого #ffc000 — заменён на зелёный.)
